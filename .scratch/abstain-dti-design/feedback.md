## 피드백 1 (단백질 구조 관점)

난이도 축 중 구조 신뢰도로 pLDDT와 PAE를 사용하는 부분이 조금 궁금했어요. BindingDB에 포함된
타겟들은 비교적 잘 구조화된 단백질이 많을 것 같아서, pocket 주변 pLDDT나 PAE 값이 높은 쪽에 몰릴
것 같은데, 그러면 이 값들만으로 difficulty group을 구분하기가 생각보다 쉽지 않을 수도 있을 것
같아서요. 실제 분포가 얼마나 넓게 나오는지 먼저 확인해보면 좋을 것 같아요!

그리고 P2Rank 기반으로 대표 pocket 하나를 정의하는 방식이라면, allosteric ligand나 여러 binding
pocket을 갖는 타겟에서는 실제 ligand-binding site와 잘 맞지 않는 경우도 있을 것 같아서, 테스트셋을
구성할 때 이런 케이스를 어떻게 처리할지도 고려하면 좋을 것 같습니다!

## 피드백 2 (과제 정의 관점)

문제의식 자체는 많은 분들이 공감할 것 같지만 지금 문서에 적힌 형태로 실제로 답할 수 있을까 하는
의문은 남는 것 같습니다.

무엇을 input으로 넣고 정확히 어떤 대상을 prediction하며, "모른다" 혹은 "난이도"를 어떤 기준으로
정의할지가 아직 충분히 정리되지 않은 상태에서 질문이 조금 크게 잡혀 있다는 느낌을 받았어요.

특히 DTI를 정확히 어떤 task로 보는지, 서열이나 분자 유사도 같은 값이 왜 실제 문제의 난이도를
대변한다고 볼 수 있는지, 그리고 LLM이 실제 prediction 과정에서 어떤 역할을 하는지가 먼저 명확해져야
전체적인 방향에도 더 공감이 갈 것 같습니다.

현재 drug discovery에서 LLM은 질문의 성격에 따라 적절한 tool을 호출하고 외부 도구가 반환한 결과를
조합하거나 전달하는 역할에 가까운 경우가 많은 것 같은데, 그렇다면 여기서 평가되는 "정확도"가 적절한
tool을 선택하고 필요한 단계를 끝까지 수행했는지를 보는 것인지, 아니면 LLM 자체의 prediction이나 판단
능력을 보는 것인지가 조금 더 구분되면 좋을 것 같습니다.

이런 부분들을 초반에 좀 더 구체적으로 정의하고, 가능하면 domain expert들에게 한 번 검증받은 뒤
진행하면 프로젝트의 방향도 훨씬 선명해지고 의미 있는 결과물로 이어지기 쉬울 것 같다는 생각이
들었습니다.
